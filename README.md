#  Ejercicio 8 — Registro de Mascotas
---

## 📝 Descripción

El sistema permite registrar la información de una mascota en una clínica veterinaria y simular el envejecimiento o crecimiento progresivo del animal, manteniendo su ficha de datos actualizada.

---

## 🚀 Funcionalidades y Requerimientos

### 📦 Clase `Mascota`

* **Atributos:**
  * Nombre (Cadena de texto / String)
  * Especie (Cadena de texto / String — ej. Perro, Gato, Ave)
  * Edad (Número entero / Int)

* **Métodos:**
  * IncrementarEdad(): Incrementa en 1 la edad de la mascota.
  * MostrarInformacion(): Imprime en pantalla la ficha técnica con el nombre, especie y edad actual del animal.

---

## 💻 Programa Principal (`main`)

Ejecuta la siguiente simulación:
1. Instancia al menos una **mascota** con sus datos iniciales.
2. Muestra el estado inicial de la ficha.
3. Simula el paso del tiempo aplicando **múltiples incrementos de edad**.
4. Muestra la evolución del crecimiento en cada ciclo.
